# Selva Creations

Selva Creations is a modern static landing page for design classes in Chennai. It promotes Photoshop, wedding album design, and graphic design training with a clean premium look.

## Project files

- `index.html` — main website page
- `LOGO.png` — brand logo used in the header and footer
- `README.md` — project instructions

## GitHub Pages deployment

1. Create a new GitHub repository.
2. Upload all files from this project to the repository root.
3. Open the repository on GitHub.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)` folder.
7. Click **Save**.

Your website will be published and a live URL will be generated.

## Custom domain

To use `selvadesigns.in`:

1. Go to **Settings → Pages**.
2. Add the custom domain `selvadesigns.in`.
3. Update your domain DNS settings as instructed by GitHub.

## Notes

- This is a static HTML website.
- No installation or build command is required.
- The site is designed for simple deployment on GitHub Pages.
